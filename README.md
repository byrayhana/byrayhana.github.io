# byrayhana.github.io

Source for my personal site: **https://byrayhana.github.io**

Single-page [Jekyll](https://jekyllrb.com/) site on GitHub Pages. No theme gem; one layout, one stylesheet, light and dark mode.

## Local preview

```bash
bundle install
bundle exec jekyll serve
# open http://localhost:4000
```

## Structure

```
_config.yml            name, tagline, description, profile links (used for SEO sameAs)
_layouts/default.html  head: meta tags, Open Graph, Person JSON-LD
index.html             page content
assets/css/style.css   styles
robots.txt             points crawlers to sitemap.xml (generated by jekyll-sitemap)
```
