2026 · inference

Benchmarks that lie

A reported 4–5× speculative-decoding speedup turned out to be a comparison against a baseline with CUDA graphs switched off. Same story with a model I had written off as slow. I now check the flags before I believe the number.

--enforce-eager: ~15 tok/s → graphs on: 147 tok/s
2026 · agents

Grading agents, not answers

Trajectory-level evaluation for a production agent platform on MCP tools. Each question runs k times, each run is traced end to end, and each step is graded: which tool, in what order, whether the citations are real, and what it cost. It became the release gate for new tool servers.

every run traced · every tool call checked · pass^k
